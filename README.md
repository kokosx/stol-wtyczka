# Stół — wtyczka do przeglądarki

Wtyczka Stołu do Chrome i Firefoksa. Dokleja panel czatu Stołu (https://stol.bkokoszewski.eu) do Google Chat i Gmaila.

To repo służy tylko do pobierania gotowych paczek. Najnowsza wersja: **[Releases → Latest](https://github.com/kokosx/stol-wtyczka/releases/latest)**.

## Instalacja

**Chrome (i inne oparte na Chromium)**
1. Pobierz `stol-chrome-X.Y.Z.zip` i rozpakuj do folderu, którego nie będziesz usuwać.
2. Wejdź na `chrome://extensions` i włącz „Tryb dewelopera”.
3. „Załaduj rozpakowane” → wskaż rozpakowany folder.

Aktualizacja: podmień zawartość folderu na nową wersję i kliknij „Odśwież” przy wtyczce.

**Firefox**
Paczka nie jest podpisana przez Mozillę, więc da się ją wczytać tylko tymczasowo (do zamknięcia przeglądarki):
`about:debugging` → „Ten Firefox” → „Załaduj tymczasowy dodatek” → wskaż `stol-firefox-X.Y.Z.zip`.
